# UI Examples Reference (Context Feeding)

This directory contains reference implementations of complex UI components.
**AI Agents must check these examples** to ensure they are building components matching the expected architecture, design tokens, and animation standards.

## ReferenceCard.jsx
A standard complex card that demonstrates:
- Tailwind utilities (`p-6`, `flex`, `gap-4`, etc.)
- Design tokens (`bg-background`, `text-foreground`, `border-border`, etc.)
- Micro-interactions (hover states, Framer Motion integration)
- 4-State UI structure (`Initial`, `Loading`, `Error`, `Hover/Active`)
