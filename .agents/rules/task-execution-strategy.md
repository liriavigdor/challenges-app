# Task Execution Strategy

To ensure high-quality results and minimize errors, follow this execution strategy for all tasks:

1. **Step-by-Step Execution:** Even if you receive a long, multi-part prompt, do not attempt to execute all parts simultaneously.
2. **Work Incrementally:** Isolate the tasks and work on them **one by one, separately**.
3. **Verify Before Proceeding:** Complete a single small task, verify its success (e.g., check for bugs, ensure it meets requirements), and only then move on to the next part of the prompt.
4. **Pause for Feedback:** If a prompt contains multiple major parts, it is acceptable to stop after completing a chunk to request user confirmation before proceeding to the next chunk.
